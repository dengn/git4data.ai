网站统计与隐私

我们使用本站托管在 Cloudflare 的统计接口，了解各页面的浏览量、链接和按钮点击量，以及视频的开始播放和播完次数。数据以 UTC 日期、预定义页面和事件名称汇总，保留最近 180 天；Cloudflare 的备份可能有额外保留期。统计从上线后开始，无法补回历史访问。

记录哪些信息？

统计数据库只保存日期、页面代号、事件类型、预定义控件代号和次数。不保存 IP、用户标识、Cookie、浏览器指纹、来源地址、查询参数、SQL、表单输入、数据库内容或个人浏览轨迹。Cloudflare 为网络服务和请求限流可能处理 IP 等连接信息，这些不会写入我们的统计表。

如何理解这些数字？

浏览量是页面在浏览器中可见时发出的事件次数；刷新和浏览器历史恢复会再次计数。点击量统计链接和按钮的激活次数，同一个人可以贡献多次。视频开始和播完每个页面载入各计一次。它们不代表独立用户数、安装数、真实下载完成数或可靠的用户转化率。脚本屏蔽、关闭页面、网络故障、隐私偏好、限流和机器人过滤都可能影响覆盖；也无法保证识别所有自动化访问。

你的选择

统计尊重浏览器的 Do Not Track 和 Global Privacy Control 信号。你也可以关闭当前浏览器的统计；我们仅在本机保存一项退出偏好，不生成访客标识。加入 ?analytics=off 可以临时关闭当前页面统计。以下开关不会覆盖浏览器已启用的隐私信号。

下载 Skill 与 GitHub

安装后的 Skill 没有运行时遥测。ZIP 由 GitHub 提供下载，GitHub 的公开下载计数与本网站的“点击下载按钮”是两项独立指标。下载页必要时会直接读取 GitHub 的公开 Release 元数据，不发送 Cookie 或本站访问来源。

English summary

We collect first-party aggregate page views, link/button activations and video starts/completions. The analytics store retains daily UTC counts for 180 days, with no visitor IDs, IP addresses, cookies, fingerprints, referrers, query strings, SQL or form values. Cloudflare separately processes connection information for hosting and transient rate limiting. These are event counts, not unique people or verified conversions. Browser privacy signals, opt-outs, blockers and network failures can reduce coverage; bots may remain. The installed Agent Skill has no runtime telemetry. GitHub release downloads are a separate metric.
