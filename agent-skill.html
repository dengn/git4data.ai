Instructions guide the agent. Permissions enforce the boundary.

The proposal agent should only be able to write its own branch. Keep production and merge credentials with a separate operator or service. Branches isolate data changes; heavy work still needs resource limits or a separate workspace instance.

When do you need another tool?

Operator-led workflow

Use this skill with a MySQL client. An operator provisions restricted branch access and promotes reviewed changes in a separate session. No dedicated MCP server is required.

Available in this download

Unattended or multi-user workflow

Add a local CLI or service that owns credentials and enforces workspace scope, immutable proposals, approvals, resource limits, and merge recovery. MCP is one optional interface. That service is not included in this release.
